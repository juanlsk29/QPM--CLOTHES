# Artefactos Scrum - QPM Clothes

## Product Goal
Entregar una aplicación de terminal clara y funcional que permita a la persona encargada de una tienda administrar el ciclo de vida de pedidos de ropa, desde su registro hasta su entrega o cancelación, con datos persistentes y validaciones que reduzcan errores de seguimiento.

## Definition of Done
Una historia se considera Done cuando cumple sus criterios de aceptación, está integrada, el código es comprensible, las entradas y errores se controlan, se prueban casos válidos e inválidos relevantes, la persistencia y los reportes funcionan cuando aplican, el README y la documentación reflejan la versión real y los cambios quedan revisables en GitHub. Los defectos críticos conocidos se resuelven antes del cierre técnico.
